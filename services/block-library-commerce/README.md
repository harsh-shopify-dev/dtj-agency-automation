# DTJ Commerce (fifth theme app extension)

Why it exists: the shopping sections a multi-product HOME page needs (category tiles, bundles and offers, a press strip, ...). DTJ Heroes is full (94 of 100 KB), so these live in their own app.
Design and limits: `docs/block-library-design.md`; state and history: `docs/HANDOFF.md`. Harsh's list of what a multi-product home page needs and we lacked (13 Oct 2026): shop by category, bundles and
offers, press / logo strip, best sellers in our look, a "which one is right for me" finder, before and after, an offer banner. "We will create 2 more after this" (Harsh).

**Status (13 Oct 2026): built and tested locally ONLY. The app does not exist in the Dev Dashboard yet, nothing is deployed, no store has it.**
`shopify.app.toml` is a placeholder (`client_id = ""`) until Harsh creates the app and links it.

## Verified / not verified
Verified (13 Oct 2026): 108 unit tests; library rules and size budget; Shopify Theme Check (only the usual ExcessiveSettingsCount warning); headless-browser renders of all three layouts on desktop and phone with stand-in pictures.
Found while building: Shopify allows only ONE `collection` setting per block (library rule), and the local test engine mis-reads `nil != blank` and `>=`; both are handled and tested.
NOT verified: Judge.me reading on a real store (the markup format comes from Judge.me's public documentation and community examples, not from a store with Judge.me installed: until it is seen working on a real product the rating is UNVERIFIED), the cart button and swatch swap in a browser (only markup and code tests), whether the theme's cart icon updates after Quick add (the block does not talk to the theme's cart drawer), a deploy, the theme editor, the real collection pictures, a real phone, other browsers, tablet widths.
