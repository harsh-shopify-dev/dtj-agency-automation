DTJ store factory · team guide · 12 Oct 2026

Start here, whatever your job

How DTJ makes Shopify product pages and switches its apps on or off on every shop, without depending on one person. Most people only need Telegram (part 1). Designers also do part 2; a developer taking over does part 3.

1Everyone: the Telegram bot (2 minutes)

  1. In Telegram, search @DtjPageDesignerBot and send /start.
  2. It replies with your number. Send that number to Harsh. If Harsh doesn't answer, send it to any teammate who already uses the bot; they tell Claude "add <your name> to the bot, number <number>".
  3. You then have full access:
    • A product page: send a product link from the shop's website (a note after it is fine). The bot sends the preview link back when the page is ready.
    • The app switch: /shops lists every shop and whether DTJ's apps are ON; /status shop shows one; /off shop and /on shop switch them after you tap a confirm button.

2Designers: a laptop that designs the pages (30 minutes, once)

You'll receive privately (never in a group chat)

  • the DTJ Claude login (the team's shared account)
  • an invite to the GitHub repo harsh-shopify-dev/dtj-agency-automation (make a free account at github.com first, and accept the invite from your email)
  • an n8n invite to your email (accept it and set a password)
  • a Bitwarden Send link with the Theme Access password of each shop you'll design for

Install Claude

Open claude.ai/download, download Claude for Windows, install it and sign in with the DTJ Claude login.

Open PowerShell

Press the Windows key, type PowerShell, click Windows PowerShell. To run a command: copy it, right-click inside PowerShell to paste, press Enter, and wait for the line to end with > again.

Install Git

winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements

When it's done, close PowerShell and open it again. If it says "winget is not recognised": install App Installer from the Microsoft Store, then try again.

Download the project

cd $HOME
git clone https://github.com/harsh-shopify-dev/dtj-agency-automation.git

A GitHub window opens the first time: sign in with the GitHub account that got the invite.

Let Claude set everything up

In Claude, open the Code tab, choose the folder dtj-agency-automation in your user folder, and type:

Type in Claudeset up the store factory

Claude installs what's missing and opens a terminal tab for the two things only you can type: your n8n token (in n8n: Settings > MCP Access) and your shop passwords. Type them only in that terminal tab, never in the chat, and type nothing there after it says "Done". Claude finishes with "Ready".

Design pages

Type in Claudelisten for the telegram call

Claude designs every request people send to the bot, while you're at the laptop (it stops after 8 hours). Only one laptop should listen at a time. For a single page instead: handle the Claude Code trigger in n8n.

3A developer taking over the technical side

  1. Bitwarden: Tushar or Harsh adds you to the DTJ organization (the free plan has 2 members, so the person leaving is swapped out).
  2. Do part 2. The setup then fills every key from the vault.
  3. Read, in the project: docs/ACCESS-AND-KEYS.md (every account and key, and the leave checklist) and the newest entry of docs/HANDOFF.md (what is open right now).
  4. Get added to: the GitHub repo (admin), Cloudflare (DTJ's account), n8n (owner), Hostinger and the Shopify Dev Dashboard organization that owns DTJ's apps.

4If Harsh doesn't answer: who decides

No yes needed

  • The bot
  • Designing pages into a shop's draft theme
  • The app switch (it has its own confirm button)

A yes from Harsh, or any teammate

  • Deploying the install service
  • Releasing app updates
  • Creating a store
  • Publishing an n8n workflow
  • Anything customers see live

When Harsh isn't reachable, tell Claude: "Harsh isn't reachable, I approve <the action>", with your name. One yes covers one action.

Never, whoever asks

  • Deleting things
  • Force-pushing code
  • Passwords or keys in any chat

5"We need a store ready in a few hours"

About 20 minutes a page

The shop is already set up

It shows in /shops. Send product links to the bot, and a designer types listen for the telegram call.

1 to 3 hours

A brand-new shop

In Claude, type add a new shop; it walks through every step. From the client you need collaborator access for DTJ and the store owner available to click three install links. A shop inside DTJ's own Shopify organization takes about 30 minutes.

Passwords and keys: only ever in the hidden prompts and terminal tabs Claude opens, or in Bitwarden. Never in WhatsApp, Telegram, email, a document or the Claude chat.

Who to ask: Harsh first. If he isn't reachable, Tushar. If neither is, any teammate on the bot: the rules in part 4 let you carry on.

The full guide is in the project once you've downloaded it: docs/TEAM-GUIDE.md and docs/START-HERE.md.
