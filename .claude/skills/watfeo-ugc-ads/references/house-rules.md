# House rules (Harsh's corrections, Aug-Oct 2026)

Each rule exists because a draft or an ad broke it. The reason is next to it, so a new case can be judged by the reason.

| # | Rule | Why (what went wrong) |
|---|---|---|
| 1 | One setup for the whole ad: same room, light, clothes, phone position. A new beat is a prop change, never a location cut. | Harsh: "in no UGC video we will use different setup." A reference with two rooms was copied with two rooms. |
| 2 | 9:16 vertical by default; 16:9 only when Harsh asks for that ad. | A 16:9 draft had to be redone. |
| 3 | The last clip ends with a spoken CTA: "Read Now", "Shop Now" or "Abhi padhe". Never "link in bio" / "link bio mein hai". | The CTA was left to captions; then "link bio mein" was rejected. |
| 4 | Lines sound spoken, not written: fillers (yaar, na, matlab, basically, literally, honestly, toh), self-interruptions ("..."), loose grammar, code-switching. No parallel copywriting between clips. Read each line aloud. | A Hindi draft was "too robotic": clean, parallel, topic-sentence-first. |
| 5 | Never repeat: no two ads anchor on the same character+conflict; every ad connects to a different real-life moment; vary the first line's structure ("Okay so..." and "So there's this part..." are used up). Check `references/scripts-library.md` and the angle ledger first; record the angle after. | A batch of 5 used Harsh+father 3 times and Malar's health twice. |
| 6 | Only what is in the book: no invented names, plot, dialogue or numbers. "Don't use any name if not provided in the book." | An early draft added a name. |
| 7 | The speaker reacts to the story. No invented personal history, no fake reviews, no invented reader numbers. | DTJ rule; the book-01 run kept to this. |
| 8 | Talk about the book, not the product's physical quality (thin/thick paper, discounts) unless the facts say so. | A haul-style adaptation drifted into paper quality and discounts. |
| 9 | Prompts are written directly in the chat (one code block per clip, no clip numbers or timestamps inside the prompt), and also saved. | Harsh wants to paste them straight into Flow. |
| 10 | Be fast: reference analysis in 2-3 minutes (Whisper small on the audio; Harsh sends screenshots for the look). | A forensic pass took too long. |
| 11 | One book state per clip (held up / on lap / at chest / cover to camera), held steadily; changes only between clips. | book-01 v2: the book dropped, vanished, floated, teleported at cuts; hands melted. |
| 12 | Captions at the bottom mark (~69 % down). Top (~14 %) only when the top is empty and the bottom would hide the title. | A caption covered her face. |
| 13 | Faces and rooms must look like real Indian book creators: different skin tones, face shapes, clothes, real messy bookshelves. Never the same "AI girl" face. | Harsh, 21 Oct 2026: the book-01 character "looked like AI". |
| 14 | Realism is measured, not assumed: wobble and sharpness in phone range (`scripts/realism.py`); check the cover's small print by eye. | Omni takes are tripod-steady and over-crisp; Omni garbled pack text on another product. |
| 15 | The terrace rescue scene is reserved. | Ad-restriction risk; Harsh parked it. |
| 16 | Nothing is posted and no ad is started from this skill. The reel goes to a person. | Spending money and client-visible changes need a person's yes. |
