# Motion in the fixed sections: one setting table per vibe

The sections are fixed, so motion is decided by a few settings of the fixed blocks, never by adding or removing sections. Motion
pulls the eye to what sells on energetic and playful pages, and cheapens editorial, premium and calm ones. Our blocks and
Horizon respect `prefers-reduced-motion`; never add motion that ignores it.

## The moving parts of the fixed set
| Section | Block | Setting(s) |
|---|---|---|
| W04, W09 benefit strips | `dtj-marquee` | `speed` (lower = slower), `pause_on_hover` |
| W03 customer videos | `dtj-shoppable-reels` | videos autoplay muted (sound by tap); images do not move |
| W07 reviews | `dtj-testimonials-slider` | arrows / dots only (shopper-driven) |
| W15 final push | `dtj-slideshow-pro` (one slide) | `autoplay` off, `show_progress` off (one slide never moves) |
| W02 buy box (optional) | `dtj-rotating-text` | typewriter phrases: only where the table says yes |
| Theme | Horizon | sections fade in on scroll (theme setting, not ours) |

## The table
| Vibe | W04 / W09 marquee | W03 videos | Rotating headline in the buy box | Decorative dividers |
|---|---|---|---|---|
| electric | moving, fast-medium, W09 the other way | yes | yes (use moments: "for work / workouts / drives") | one allowed |
| playful | moving, medium | yes | yes | one allowed |
| appetite | moving, slow | yes (food in motion) | no | no |
| fresh | moving, slow | yes | no | no |
| natural | moving, very slow | yes | no | no |
| calm | slowest the block allows, pause on hover | images only (no autoplay) | no | no |
| premium | slowest, pause on hover | images only | no | no |
| editorial (fashion) | slowest, pause on hover; never over product photos | images only | no | no |

Always: at most one self-moving element visible on a 390 x 844 phone screen at a time (the review checks it); nothing that moves
carries prices, offers or terms; autoplay video is muted with a visible sound control and never covers the buy button.
